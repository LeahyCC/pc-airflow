# PC Airflow

A free, open source web app that shows how air and heat move inside a PC case. Build a PC, set how hard it's working, see where the hot air goes, then change one thing and compare.

Runs entirely in your browser on your own graphics card (WebGPU). No accounts, no server.

Early days: the specs and project skeleton are in, the app isn't built yet.
